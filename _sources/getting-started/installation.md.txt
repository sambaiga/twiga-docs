# Installation & Setup

Source: `pyproject.toml`

## Quick Install

```bash
pip install twiga
```

## Development Setup with uv

For development, use [uv](https://docs.astral.sh/uv/) to manage dependencies:

```bash
# Clone the repository
git clone https://github.com/sambaiga/twiga-forecast.git
cd twiga-forecast

# Create a virtual environment and sync all extras
uv sync --all-extras
```

## Optional Dependency Groups

Twiga uses optional dependency groups to keep the base install lightweight. Install only what you need:

| Group | Purpose | Install Command | Key Packages |
| --- | --- | --- | --- |
| `nn` | Neural network models (PyTorch + Lightning) | `pip install twiga[nn]` | `torch`, `lightning`, `torchmetrics`, `tensorboard` |
| `gbtree` | Gradient boosting + NGBoost | `pip install twiga[gbtree]` | `xgboost`, `catboost`, `lightgbm`, `ngboost`, `quantile-forest` |
| `plots` | Visualization | `pip install twiga[plots]` | `lets-plot`, `matplotlib`, `plotly`, `scienceplots` |
| `mlops` | Production MLOps stack | `pip install twiga[mlops]` | `mlflow`, `fastapi`, `uvicorn`, `evidently`, `prefect` |
| `explain` | Model explainability | `pip install twiga[explain]` | `shap` |
| `tuning` | Optuna dashboard | `pip install twiga[tuning]` | `optuna-dashboard` |
| `tracking` | Experiment tracking | `pip install twiga[tracking]` | `tensorboard` |
| `docs-sphinx` | Sphinx documentation | `pip install twiga[docs-sphinx]` | `sphinx`, `pydata-sphinx-theme`, `myst-parser` |
| `dev` | Development tools | `pip install twiga[dev]` | `ruff`, `pre-commit`, `commitizen` |
| `test` | Testing | `pip install twiga[test]` | `pytest`, `pytest-cov`, `pytest-xdist` |

To install multiple groups at once:

```bash
pip install twiga[nn,gbtree,plots]
```

## PyTorch Backend

### CPU Only

```bash
pip install torch>=2.8.0 --index-url https://download.pytorch.org/whl/cpu
```

### CUDA (GPU)

```bash
pip install torch>=2.8.0 --index-url https://download.pytorch.org/whl/cu124
```

:::{admonition} Note
:class: note

GPU support is optional. All ML models run on CPU by default. Neural network models benefit from GPU acceleration but work on CPU as well. CatBoost supports GPU training via `task_type="GPU"` and XGBoost via `device="cuda"` in their respective configs.
:::

## Core Dependencies

The base install includes:

| Package | Version | Purpose |
| --- | --- | --- |
| `pydantic` | >=2.10.6 | Configuration validation |
| `numpy` | 2.0.0 | Numerical computation |
| `pandas` | >=2.2.3 | Data manipulation |
| `scikit-learn` | >=1.8.0 | Base transformers and utilities |
| `optuna` | >=4.7.0 | Hyperparameter optimization |
| `statsmodels` | >=0.14.0 | Statistical modeling |
| `astral` | >=3.2 | Sunrise/sunset calculations |
| `rich` | >=14.3.1 | Progress bars |
| `tqdm` | >=4.66.4 | Progress bars |

## Prerequisites

- **Python**: 3.12+ (required — `>=3.12`)
- **OS**: Linux, macOS, Windows
- **GPU**: Optional, for neural network models and CatBoost GPU mode

## Verification

```python
import twiga
from twiga.forecaster.core import TwigaForecaster
from twiga.core.config import DataPipelineConfig, ForecasterConfig

print("Twiga installed successfully!")
```

To verify GPU availability for neural models:

```python
import torch
print(f"CUDA available: {torch.cuda.is_available()}")
print(f"Device: {torch.cuda.get_device_name(0) if torch.cuda.is_available() else 'CPU'}")
```
