Installation & Setup#

Source Files

  • pyproject.toml

Quick Install#

pip install twiga-forecast

Development Setup with uv#

For development, use uv to manage dependencies:

# Clone the repository
git clone https://github.com/sambaiga/twiga-forecast.git
cd twiga-forecast

# Create a virtual environment and sync all extras
uv sync --extra pytorch --extra lightning --extra gbtree --extra plots --extra dev --extra test

Optional Dependency Groups#

Twiga uses optional dependency groups to keep the base install lightweight. Install only what you need:

Group

Purpose

Install Command

Key Packages

Neural network models

pip install twiga-forecast[pytorch]

pip install twiga-forecast[lightning]

lightning>=2.6.0, torchmetrics>=1.8.2

Gradient boosting models

xgboost>=3.1.3, catboost>=1.2.8, lightgbm>=4.6.0

Visualization

pip install twiga-forecast[plots]

altair, lets-plot, seaborn, plotly, matplotlib_inline

tracking

Experiment tracking

pip install twiga-forecast[tracking]

wandb>=0.19.10, tensorboard>=2.19.0

docs

Documentation generation

pip install twiga-forecast[docs]

mkdocs, mkdocstrings-python, mkdocs-material

dev

Development tools

pip install twiga-forecast[dev]

ruff, mypy, pre-commit, commitizen

Testing

pip install twiga-forecast[test]

pytest>=9.0.2, pytest-cov>=7.0.0

To install multiple groups at once:

pip install twiga-forecast[pytorch,lightning,gbtree,plots]

PyTorch Backend#

CPU Only#

pip install torch>=2.8.0 --index-url https://download.pytorch.org/whl/cpu

CUDA (GPU)#

pip install torch>=2.8.0 --index-url https://download.pytorch.org/whl/cu124

Note

GPU support is optional. All ML models (CatBoost, XGBoost, LightGBM, Linear Regression) run on CPU. Neural network models benefit from GPU acceleration but work on CPU as well. CatBoost also supports GPU training via task_type="GPU" in its config.

Prerequisites#

  • Python: 3.11 (required - >=3.11,<3.12)

  • OS: Linux, macOS, Windows

  • GPU: Optional, for neural network models and CatBoost GPU mode

Verification#

import twiga
from twiga.forecaster.core import TwigaForecaster
from twiga.core.config import DataPipelineConfig, ForecasterConfig

print("Twiga installed successfully!")

To verify GPU availability for neural models:

import torch
print(f"CUDA available: {torch.cuda.is_available()}")
print(f"Device: {torch.cuda.get_device_name(0) if torch.cuda.is_available() else 'CPU'}")
